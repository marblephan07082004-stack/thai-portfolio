# Thai Phan — Mechanical Engineering Portfolio

Personal portfolio site for Thai Bao Ngoc Phan (UCLA Mechanical Engineering, class of 2028).
Built with Next.js 14 (App Router), TypeScript, and Tailwind CSS.

**Sections:** Projects (HAcK Stormcaster, Quarter-Car Suspension, MED4Ü Pill Dispenser), Experience, Skills, Education, Contact.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Edit your content

All text lives in `lib/constants.ts`: profile, education, experience, projects, skills, and involvement.
Images go in `public/images/` and are referenced by path in the same file.

## Deploy

Import this repo at [vercel.com/new](https://vercel.com/new). No settings needed.
